Ja — men här skulle jag inte försöka skapa själva tabellen med ett measure. Ett measure kan inte skapa rader. Vi låter IPT Upcoming Current stå för raderna och använder ett display-measure för att göra varje kommande körning väldigt lättläst.

Testa först detta measure:

Upcoming Run Display =
VAR __Start =
    SELECTEDVALUE ( 'IPT Upcoming Current'[PlannedStart] )
VAR __Robal =
    SELECTEDVALUE ( 'IPT Upcoming Current'[CurrentRobal] )
VAR __Material =
    SELECTEDVALUE ( 'IPT Upcoming Current'[MaterialNumber] )
VAR __Batch =
    SELECTEDVALUE ( 'IPT Upcoming Current'[FgBatch] )
VAR __LSP =
    SELECTEDVALUE ( 'IPT Upcoming Current'[LspNumber] )
VAR __Qty =
    SELECTEDVALUE ( 'IPT Upcoming Current'[CartridgeQuantity] )
VAR __Stage =
    SELECTEDVALUE ( 'IPT Upcoming Current'[UpcomingStage] )
RETURN
    FORMAT ( __Start, "ddd dd MMM · HH:mm" )
        & "  ·  "
        & COALESCE ( __Robal, "ROBAL ?" )
        & UNICHAR ( 10 )
        & COALESCE ( __Material, "Unknown material" )
        & "  ·  FG "
        & COALESCE ( __Batch, "—" )
        & "  ·  LSP "
        & COALESCE ( __LSP, "—" )
        & "  ·  "
        & FORMAT ( __Qty, "#,0" )
        & " carts"
        & UNICHAR ( 10 )
        & COALESCE ( __Stage, "—" )

Sedan gör du en Table visual och lägger in bara:

* LotKey
* Upcoming Run Display

Sortera på:

PlannedStart → Ascending

Och i Format:

* Word wrap = On
* Row padding ungefär 8–10
* Grid vertical = Off
* Alternating rows = mycket diskret
* LotKey kan du sedan göra väldigt smal eller till och med ta bort när vi vet att varje rad blir unik ändå.
